## Guidelines

1. Download images locally; do not hotlink.
2. Use legitimate sources: Unsplash, Pexels, Wikimedia Commons.
3. Record licence and attribution requirements.
4. Optimise images for web delivery.
5. Use descriptive filenames.
6. Prefer SVG for icons and illustrations.
7. Use Lucide React for interface icons.
